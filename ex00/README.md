# Project 04 — Personal Portfolio

## 1. Project Overview

This project is a responsive personal portfolio built from scratch using HTML5, CSS3, and JavaScript ES6+.

It introduces me, presents my skills and hobbies, showcases my previous projects, and includes a contact form and an interactive theme switcher.

## 2. Technologies Used

- **HTML5:** Creates the structure and content of the website.
- **CSS3:** Controls styling, colors, Flexbox, Grid, and responsive layouts.
- **JavaScript ES6+:** Adds interactivity through DOM manipulation and event handling.
- **Git & GitHub:** Used for version control and sharing projects.

## 3. Features

- Header and navigation bar.
- About Me section with a profile photo.
- Skills grid.
- Project showcase linking to Projects 00–03.
- Hobbies section.
- Contact form with browser validation.
- Interactive light/dark theme switcher.
- Responsive design for desktop and mobile screens.
- Footer with an automatically updated copyright year.

## 5. How to Run

1. Open the `ex00` directory.
2. Open `index.html` in a web browser.
3. Use the navigation links to explore the sections.
4. Click the theme switcher to change the page appearance.
5. Test the contact form using sample information.

No frameworks, templates, UI libraries, or package installations are required.

## 6. JavaScript Feature

The theme switcher listens for a click event. Its callback toggles the `dark-theme` class on the body element. CSS variables then update the page colors without reloading the page.

## 7. Contact Form Note

The contact form demonstrates front-end validation and JavaScript event handling. It does not send messages to an email address or server.
